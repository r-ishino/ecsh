# exec

`ecsh exec` は使い捨てタスクを起動し、ECS Exec で入れるようになったら入る。抜けたらタスクを止める。

```sh
ecsh exec                           # プロファイルを選んで起動し、入る
ecsh exec staging                   # プロファイルの一覧を飛ばす
ecsh exec staging -y                # 起動前の y/N も省く
ecsh exec --size                    # タスクの大きさを一覧から選ぶ（size.md）
ecsh exec --cpu 2 --memory 8GB -y   # 大きさを直接指定する（size.md）
```

## 起動まで

- 何かを起動する前に、Session Manager plugin が `PATH` 上に実行できる形であるかを確かめる
- ネットワーク設定・起動タイプ（キャパシティプロバイダ）・プラットフォームバージョンは、プロファイルの `service` から写す。タスク定義は、サービスが今使っているリビジョンではなく、そのファミリーに登録済みの最新リビジョンを使う
- 使った AWS プロファイルと、それをどこから決めたか（環境変数 `AWS_PROFILE`・設定の `aws_profile`・SDK の既定）を出す
- 起動前に、どのプロファイルでも必ず y/N を聞く。`y` か `yes` 以外は起動をやめる。`--yes`（`-y`）で省く。stdin がターミナルでなく `--yes` も無いときは、起動せずにエラーで終わる

## タスクの中

- コンテナで `/bin/sh` を起動する。プロンプトにプロファイル名が出る（`[staging] /app # `）
- シェルを抜けるとタスクを止める
- 接続が切れるなどセッションが異常に終わっても、タスクは止める。止めるのに成功すれば、セッションの終了コードは表示するだけで、ecsh 自体は 0 で終わる
- ecsh が異常終了したときに備えて、タスクは起動から 12 時間で自分で止まる

## 表示

進み具合は stderr に出る。おおよそ次のようになる。

```
> プロファイルを選んでください staging  example-staging / worker

  staging  →  example-staging / worker / app
  AWS  example（設定の aws_profile） · us-east-1
  ネットワーク  subnet-01234567… · sg-01234567… · パブリック IP なし

staging（cluster=example-staging service=worker）で使い捨てタスクを起動します。よろしいですか？ [y/N] y
✓ タスクを起動しました  0123abcd（worker:42）
  12 時間後に自動で止まります · startedBy ecsh/alice
✓ 入れるようになりました（45 秒）
  exit で抜けるとタスクを止めます

[staging] /app # exit
✓ タスクを止めました  0123abcd（入っていた時間 12 分）
```

- タスクは ID の先頭 8 文字で、タスク定義は `family:revision` で示す。タスク ARN を全部出すのは、自分で止める必要がありそうなときだけ
- 入れるようになるのを待つ間は、経過時間とタスク・エージェントの状態をスピナーの 1 行で出す
- エラーは `✗` 付きの 1 行の要約で出し、続けて（あれば）やることと、元になった原因を出す
- AWS SSO のセッション切れで AWS の呼び出しに失敗したときは、解決した AWS プロファイルを付けて `aws sso login` を案内する
- stderr がターミナルでないとき、または環境変数 `NO_COLOR` に空でない値が入っているときは、色とスピナーを出さない。待つ間は状態が変わるたびに 1 行出す

## シグナル

タスクを起動する（RunTask を呼ぶ）前の Ctrl-C は、そのまま終わるだけ。RunTask の最中に受けたシグナルは、タスクができた後の「入れるようになるのを待つ間」に受けたものとして扱う。起動した後は次のとおり。

- 入れるようになるのを待つ間の Ctrl-C・ターミナルを閉じる（SIGHUP）・SIGTERM は、タスクを止めてから終わる
- タスクの中にいる間の Ctrl-C は、コンテナで動いているコマンドに届き、ecsh は終わらない。ターミナルを閉じる・SIGTERM はセッションを終え、タスクを止めてから終わる
- シグナルを受けてタスクを止めている間にもう一度 Ctrl-C を押すと、待たずに終わる。タスクが残るかもしれないので、`ecsh gc` で止める

## ロックファイル

タスクの中にいる間、状態ディレクトリ（`$XDG_STATE_HOME/ecsh`、`XDG_STATE_HOME` が無ければ `~/.local/state/ecsh`）の `sessions/<タスク ID>.lock` を排他ロックし、終わるときにファイルを消す。これで「この Mac から使っているタスク」だと分かる（ps の接続中）。ファイルを作れないときは、注意を出してそのまま続ける。
