# ps

`ecsh ps` は、プロファイルのクラスタにある自分のタスク（`startedBy = ecsh/$USER`）を一覧する。止める指示が出たものは除く。

```sh
ecsh ps           # プロファイルを選んで一覧する
ecsh ps staging   # プロファイルの一覧を飛ばす
ecsh ps --all     # 設定の全プロファイルを回って 1 つの表にまとめる
```

## 表

表は stdout に出るのでパイプに渡せる。注意・警告とプロファイルの一覧は stderr に出る。おおよそ次のようになる。

```
> プロファイルを選んでください staging  example-staging / worker
ID        接続      状態     起動から     タスク定義  CPU     メモリ  自動停止まで
0123abcd  接続中    RUNNING  12 分        worker:42   1 vCPU  2 GB    11 時間 48 分
89abcdef  止め忘れ  RUNNING  2 時間 5 分  worker:42   2 vCPU  8 GB    9 時間 55 分
```

- 接続
  - 接続中: この Mac の `exec` がタスクの中にいる
  - 止め忘れ: ロックファイル（[exec.md](exec.md#ロックファイル)）は残っているが、それを持つ `exec` がいない
  - 不明: ロックファイルが無い（別の Mac から起動した、または古い ecsh で起動した）
  - run: コマンドを流すタスク（[run.md](run.md)）。入る前提のタスクではない
- CPU・メモリ: タスクの大きさ。起動時に上書きした大きさ（[size.md](size.md)）も反映する
- 起動から: タスクを起動してからの時間
- 自動停止まで: 12 時間の上限までの残り時間（タスクが始まった時刻から数える）。PENDING の間と run のタスクは ─
- 止め忘れのタスクは行ごと黄色になり、表の後に `ecsh gc` で止めるよう案内する。プロファイル名を付けたときは `ecsh gc staging`、`--all` のときは `ecsh gc --all` を案内する
- 不明のタスクは、起動から 1 時間を過ぎると黄色、2 時間を過ぎると赤になる
- 表の色は、stdout がターミナルのときだけ付ける（stderr とは別に判定する）。環境変数 `NO_COLOR` が空でなければ付けない
- タスクが無ければ、stderr に 1 行出して 0 で終わる

## --all

- 全プロファイルを並行して回り、表にプロファイルの列を足す
- region・cluster・AWS プロファイルが同じプロファイルは 1 回だけ問い合わせ、名前順で先に来る方の名前で出す
- AWS プロファイルは、環境変数 `AWS_PROFILE` も含めて決めた後の値で比べる。そのため `AWS_PROFILE` があると、設定の `aws_profile` だけが違うプロファイルも 1 つにまとまる
- 失敗したプロファイル（SSO のセッション切れなど）は stderr に出して飛ばす。失敗で終わるのは、全プロファイルが失敗したときだけ
- 全プロファイルが成功したときは、要らなくなったロックファイルを消す。消すのは、持ち主の `exec` がいなくて、対応するタスクももう動いていないもの
