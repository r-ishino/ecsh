# open

`ecsh open` は、動いている自分のタスクを AWS コンソールでブラウザに開く。

```sh
ecsh open          # プロファイル・タスクを選び、タスクの詳細かログを選ぶ
ecsh open staging  # プロファイルの一覧を飛ばす
ecsh open --logs   # 最後の選択を飛ばしてログ（CloudWatch Logs）を開く
ecsh open --task   # 最後の選択を飛ばしてタスクの詳細（ECS）を開く
```

## 選び方

- 他のコマンドと同じくプロファイルを聞いた後、`ps` と同じ範囲のタスクを、タスク ID・接続・状態・起動から・タスク定義で並べる
- タスクが 1 件なら一覧を飛ばす。0 件ならその旨を出して 0 で終わる
- run のタスクは、続けてタスクの詳細とログのどちらを開くかを聞く
- `exec` が起動したタスクは `sleep` を動かすだけでログが空なので、聞かずにタスクの詳細を開く。`--logs` を付けるとエラーになる
- コンテナが `awslogs`（`awslogs-group` と `awslogs-stream-prefix` 付き）を使っていなければ、ログは開けない。聞かずにタスクの詳細を開き、`--logs` を付けるとエラーになる
- stdin がターミナルでないときは一覧を出せないので、プロファイル名を付ける。run のタスクなら `--task` か `--logs` も要る。タスクが 2 件以上あると失敗する
- 並ぶのは動いているタスクだけ。終わった run のログは `ecsh logs --open` で開く（[logs.md](logs.md#--open)）

## ブラウザ

- URL を stderr に出し、macOS の `open` コマンドに渡して既定のブラウザで開く
- ブラウザでの AWS コンソールのサインインをそのまま使う。ecsh からアカウントは切り替えられない
- ブラウザが別の AWS アカウントにサインインしていると、コンソールはタスクやロググループが見つからないと出す。プロファイルのアカウントにサインインし直して、URL を開き直す
