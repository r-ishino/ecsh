# open

`ecsh open` は、動いている自分のタスクを AWS コンソールでブラウザに開く。

```sh
ecsh open          # プロファイル・タスクを選び、タスクの詳細かログを選ぶ
ecsh open staging  # プロファイルの一覧を飛ばす
ecsh open --logs   # 最後の選択を飛ばしてログ（CloudWatch Logs）を開く
ecsh open --task   # 最後の選択を飛ばしてタスクの詳細（ECS）を開く
```

## 選び方

- 他のコマンドと同じくプロファイルを聞いた後、`ps` と同じ範囲のタスクを、タスク ID・接続・状態・起動から・タスク定義で並べる
- タスクが 1 件なら一覧を飛ばす。0 件ならその旨を出して 0 で終わる
- run のタスクは、続けてタスクの詳細とログのどちらを開くかを聞く
- `exec` が起動したタスクは `sleep` を動かすだけでログが空なので、聞かずにタスクの詳細を開く。`--logs` はエラー
- コンテナが `awslogs`（`awslogs-group` と `awslogs-stream-prefix` 付き）を使っていなければログは開けない。聞かずにタスクの詳細を開き、`--logs` はエラー
- stdin がターミナルでないときは一覧を出せない。プロファイル名を付け、run のタスクなら `--task` か `--logs` も付ける。タスクが 2 件以上あると失敗する
- 並ぶのは動いているタスクだけ。終わった run のログを開くには `ecsh logs --open`（[logs.md](logs.md#--open)）

## ブラウザ

- URL を stderr に出し、macOS の `open` コマンドに渡して既定のブラウザで開く
- ブラウザは自分の AWS コンソールのサインインを使い、ecsh からは切り替えられない。ブラウザが別の AWS アカウントにサインインしていると、コンソールにタスクやロググループが見つからないと出る。プロファイルのアカウントにサインインして、URL を開き直す
