# gc

`ecsh gc` は、ecsh が止め損ねて残ったタスクを止める。`kill -9` で ecsh を殺した、Mac の電源が落ちた、StopTask に失敗した、などで残るものが対象になる（どのみち 12 時間で自分で止まる）。

```sh
ecsh gc                # プロファイルを選び、チェックリストで選んで止める
ecsh gc staging --yes  # チェックリストを出さず、止め忘れと不明のタスクを止める
ecsh gc --all          # 設定の全プロファイルのタスクを 1 つのチェックリストにまとめる
ecsh gc --all --yes    # 定期的な掃除向け
```

## チェックリスト

`ps` と同じ範囲のタスクを、stderr にチェックリストで出す。接続の呼び名は [ps.md](ps.md#表) と同じ。

- 止め忘れと不明のタスクは、最初からチェックが付いている。run のタスクはチェック無しで並び、自分でチェックしたときだけ止める
- この Mac の `exec` が中にいるタスク（接続中）は並べない。除いた件数を出す
- Space でチェックを切り替え、Enter でチェックしたものを止める。何もチェックせずに Enter するか Esc を押すと、終了コード 1 でやめる
- 各行には、タスク ID・接続・起動から・タスク定義を出す
- 並べるタスクが無ければ、その旨を出して 0 で終わる

## 止め方

- 1 件ずつ、停止の理由（reason）を `ecsh gc` にして止める。STOPPED になるまでは待たない。1 件ごとに `✓` か `✗` を出す
- 一部が失敗しても残りは続け、最後に終了コード 1 で終わる
- 止めたタスクのロックファイルも消す
- 出力はすべて stderr

## --yes

- チェックリストを出さず、止め忘れと不明のタスクを止める。run のタスクは決して止めない
- `--yes` でもプロファイルの一覧は出る。一覧も飛ばすなら、プロファイル名を付けるか `--all` を使う
- stdin がターミナルでなく `--yes` も無いときは、何も止めずにエラーで終わる

## --all

- `ps --all` と同じように全プロファイルを回り、すべてのタスクを 1 つのチェックリストにまとめる。各行の先頭にプロファイル名が付く
- `gc --all --yes` も使える。接続中のタスクと run のタスクには触らないので、定期的な掃除に向く
- `ps --all` と同じく、全プロファイルが成功したときは要らなくなったロックファイルを消す（[ps.md](ps.md#--all)）
